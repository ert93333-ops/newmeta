# Creative Analysis

Image analysis covers:

- Layout / Composition
- Product Visibility
- Hook Analysis
- Text / Copy Analysis
- Offer / Price Analysis
- CTA Analysis
- Design / Aesthetic Analysis
- Emotional Trigger
- Placement Fit

Video analysis is timeline-based and includes:

- 0.0~0.5초
- 0.5~1.0초
- 1~3초
- 3~5초
- 5~10초
- 10초 이후

Final images must not contain guide labels. QA images may include safezone overlays and must not be uploaded as ads.

Korean text, prices, and CTA are code-rendered and validated by OCR or a layer manifest.
