# Bottleneck Diagnosis

Funnel stages:

- Tracking/Data Quality
- Delivery
- Hook/Attention
- Product Clarity
- Click Intent
- Landing Arrival
- Product Page/Offer
- Checkout
- Revenue/ROAS
- Fatigue
- Placement Fit

Data sufficiency defaults for a 50,000원/day ad budget:

- Observation: impressions < 500, link_clicks < 20, LPV < 15, purchases < 1
- Weak Signal: impressions >= 500, link_clicks >= 20, LPV >= 15
- Actionable Signal: impressions >= 1,500, link_clicks >= 50, LPV >= 30, ATC >= 5, purchases >= 2
- High Confidence: impressions >= 3,000, link_clicks >= 100, LPV >= 80, ATC >= 10, purchases >= 3

Low-sample outputs must say observation or low confidence instead of making firm claims.
